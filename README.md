# Raffle for Sunrise (Lawrenceville)

A student-led fundraising site for a Lawrenceville lunchtime raffle supporting Sunrise Day Camp Greater Philadelphia, through TTLC.

Single static page: `index.html` (no build step). Open it in a browser to preview.

## Things to edit (bottom of `index.html`)
- `DONATE_URL`: your personalized Sunrise fundraising page link
- `RAFFLE_DATE`: e.g. "Friday, December 5"
- `GOAL` / `RAISED`: progress bar numbers
- `PRICE`: ticket price (currently $2); also update the "$2" text in the page copy

Photos on the page are original placeholders; replace them with approved TTLC photos.
